## 📖 Overview

**VeloSync** is an AI-powered **Multi-Warehouse Inventory Optimization Platform** that enables businesses to efficiently manage inventory across multiple warehouses through an intuitive, responsive, and scalable web interface.

The frontend provides real-time visibility into inventory operations, warehouse performance, stock movement, purchase orders, supplier deliveries, and AI-powered demand forecasting. Designed with modern UI principles, it offers a seamless user experience for administrators, warehouse managers, and business users.

Built using **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Redux Toolkit**, the application is optimized for performance, maintainability, and scalability while integrating seamlessly with the **VeloSync .NET 8 Web API**.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/yourusername/velosync-frontend.git
```

## Navigate

```bash
cd velosync-frontend
```

## Install Dependencies

```bash
npm install
```

## Environment Variables

Create a `.env` file.

```env
VITE_API_BASE_URL=https://your-api-url/api
```

## Start Development Server

```bash
npm run dev
```

Application runs at:

```
http://localhost:5173
```
